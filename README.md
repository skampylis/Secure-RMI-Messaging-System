# Secure-RMI-Messaging-System
Σύστημα ανταλλαγής μηνυμάτων βασισμένο σε Java RMI, με υποστήριξη λογαριασμών πολλαπλών χρηστών, πραγματικού χρόνου και διαχείρισης εισερχομένων. Συγκεκριμένα, περιλαμβάνει ασφαλή επικύρωση authToken, ταυτόχρονη εξυπηρέτηση αιτήσεων στον server και παρακολούθηση κατάστασης μηνυμάτων.
